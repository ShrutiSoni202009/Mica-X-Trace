MICA-X Trace — GitHub Pages starter site

FILES
- index.html: the product profile webpage.

PUBLISH WITH GITHUB PAGES
1. Sign in to GitHub and create a new public repository, for example: mica-x-trace.
2. Upload index.html to the repository root (not inside another folder).
3. Open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch: main; folder: /(root); click Save.
6. Wait for GitHub Pages to publish. The URL will look like:
   https://YOUR-USERNAME.github.io/mica-x-trace/
7. Open that URL on your phone and check every section.
8. Only after the page is live, create a STATIC QR code pointing to that exact URL.
   Do not use a QR provider's expiring dynamic redirect.

IMPORTANT CONTENT CHECKS BEFORE PUBLISHING
- Replace the bracketed manufacturer/contact/source/compliance placeholders.
- Confirm the exact names and materials of all five layers.
- The site deliberately describes MICA-X as an idea/prototype-stage concept.
- Do not claim certified fire prevention, thermal-runaway prevention, universal compatibility,
  legal sourcing, or certification unless you have verifiable evidence.
- For a student demo, use a public project email rather than a personal phone number.
